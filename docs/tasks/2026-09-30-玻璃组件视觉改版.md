# 玻璃组件视觉改版

## 已确认的设计

- 沿用现有交易记录、日历、统计、设置和复盘流程，以 iOS 26 Liquid Glass 为视觉参考。
- 浅色采用灰白底与淡蓝紫渐变，深色同步适配；导航和操作控件使用玻璃材质，内容卡片采用较高不透明度，保证数据可读。
- 建立可复用的容器、按钮和分段选择组件，统一圆角、间距、焦点状态与禁用状态。
- 手机采用悬浮底部导航，桌面采用胶囊导航。兼容减少动态效果、减少透明度和不支持背景模糊的环境。

## 验收条件

- 五个主要页面和逐笔复盘采用一致的组件与视觉层级。
- 表单字段、统计值、截图与现有操作继续可访问；手机布局预留底部导航安全区。
- 玻璃模糊不应用于图片、图表或可能包含全屏图片预览的内容卡片。
- 浅色、深色、窄屏与复盘操作通过当前浏览器检查；Safari 和真实手机另行验证。

## 实现边界

- 使用现有 React、Tailwind 和 Lucide 依赖，不新增依赖。
- 数据结构、接口、统计口径与同步逻辑保持现状。
- 网页通过半透明材质、背景模糊、渐变高光与阴影呈现玻璃质感。

## 组件职责

- `client/src/components/ui/Glass.jsx`：`GlassSurface` 保留调用方指定的语义元素与事件；`GlassButton` 默认普通按钮，保存交易明确使用提交按钮；`GlassSegmentedControl` 采用受控值和 `aria-pressed`。
- `client/src/components/JournalNavigation.jsx`：共用导航条目，桌面胶囊与手机底部导航采用同一组页面标识，使用 `aria-current` 表示当前页面。
- `client/src/index.css`：集中维护材质变量、导航和控件样式、手机安全区及减少动态/透明度时的回退。
- 内容容器无模糊和变换，避免将交易卡片中的全屏截图预览限制在卡片内。窄屏复盘的交易标题与前后操作上下排列。

- `npm run build` 在实现后和修正后均通过，最新构建转换 2408 个模块。仍有浏览器兼容数据较旧、主 JS 包超过 500 KB 的非阻塞提示。
