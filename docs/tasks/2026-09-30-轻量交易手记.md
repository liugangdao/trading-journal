# 轻量交易手记

## 目标与验收

- 新建交易围绕时间/品种、方向、市场环境、Setup、入场理由、失效条件、退出原因、最终结果、执行评价九项；最终结果允许同一笔分别填写 R 和美元盈亏，核心文字与评价清晰可见，约一分钟能完成一单。
- 结束后回答“遮住盈亏是否仍是好交易”，不以盈亏代替执行评价；未结束交易可先记计划、以后补结果。
- 每笔交易可从文件选择或剪贴板粘贴图片，按账号隔离保存；复盘时在该笔详情查看，删除交易后图片一起删除。
- 旧周/月复盘和交易政策不再出现于页面；日历按交易日期显示笔数，点日期查看当天交易。
- 原有统计与完整交易记录继续可访问；旧记录保留价格、盈亏、持仓及编辑路径。交易记录页可按顺序逐笔切换，边看截图边复盘。
- 设置可按周维护目标，记录交易时显示当周目标。
- 品种管理默认折叠，初始清单为 XAUUSD、EURUSD、USDCAD、BTCUSD、USOIL；仅管理名称，页面不显示点差成本。
- 退出原因区分结构止损、移动止损、measured move目标、手动平仓。执行评价可多选七种标签；提前或手动平仓须记录原因。最终结果与执行评价上下排列。
- 逐笔复盘的截图在上、交易说明在下；点“编辑这笔交易”可在复盘页内修改当前记录。
- 统计移除连胜提示和策略分析；累计美元盈亏按交易日聚合。突出胜率、平均盈利 R、平均亏损 R、期望值与违规率，展示逐日和截至当日期望值曲线。
- 移除 TradingView 图表入口和组件使用；旧交易及旧复盘数据保留，不做破坏性迁移。

## 实现决策

- 沿用 React、Express、SQLite 和现有登录会话。新字段增量迁移到 `trades`；旧价格与盈亏字段保留兼容旧记录与导入。
- 截图独立存入 SQLite 图片表，通过带登录会话的接口访问，限制格式与大小；交易列表仅返回图片数量，避免传输图片二进制。
- 周目标按用户与 ISO 周键保存，允许修改。旧复盘和政策接口保留供历史数据兼容，页面不再调用。
- 新版使用一条记录贯穿计划与结束。`open` 表示尚未结束，填写 R 或美元盈亏中的任一项并完成执行评价后为 `closed`；两个数值独立存储，可以同时存在。
- 用户纠正了首版导航误删原有统计和交易记录：恢复两处入口。美元统计纳入所有填写美元盈亏的已结束交易，R 另行汇总；一笔交易可同时显示两者，不做单位混算。
- 新注册用户预置五个品种；对仍完全保持旧版 23 品种清单的账号，启动时改为五个。已经自定义的清单不迁移，历史交易记录不删除。旧 `spread_cost` 列只为兼容保留。
- 新退出原因与执行标签分别写入 `exit_reason`、`execution_tags`；沿用 `execution_note` 保存平仓原因。旧 `risk_plan` 与 A/B/C `score` 不覆盖，旧记录在详情中仍可查看。
- R 统计只采用已结束且有有效 R 的记录，包括新记录手填 R 与可推算 R 的旧记录；持平交易计入胜率和败率的分母。期望值按 `胜率 × 平均盈利R − 败率 × 平均亏损R` 计算。违规率以有执行评价的交易为分母，新记录出现任一非“计划内”标签、旧评分为 C/D 时计为违规。
