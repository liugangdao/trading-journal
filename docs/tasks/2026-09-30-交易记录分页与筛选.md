# 交易记录分页与时间筛选

## 目标与验收

- 交易记录只展示轻量手记与 Hyperliquid 同步记录；旧版交易明细不出现在这个列表及逐笔复盘中，原数据保留。
- 服务端按开仓时间倒序分页，每页 20 笔；起止日期筛选作用于总数、列表和逐笔复盘。
- 逐笔复盘的上一笔、下一笔能跨页切换，编辑后保持当前位置并刷新列表。
- 日历和统计维持现有数据口径；统计只在进入统计页时读取全量数据，避免交易记录页加载全量。
